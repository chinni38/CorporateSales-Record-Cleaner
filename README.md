# Corporate Sales Record Cleaner
**Week 1 Milestone Project — Automated Data Sanitization Pipeline**

## Overview
This Python project cleans a deliberately messy corporate sales dataset using **Pandas** and **NumPy**. It removes exact duplicate rows, handles missing values, standardizes text, normalizes dates, and exports a cleaned CSV plus summary statistics.

## Project files
- `raw_sales.csv` — sample uncleaned dataset (includes missing values, inconsistent text, and a duplicate row).
- `sales_cleaner.py` — complete reusable cleaning script.
- `cleaned_sales.csv` — cleaned dataset generated by running the script.
- `baseline_summary_statistics.csv` — statistics before cleaning (`describe(include="all")`).
- `cleaned_summary_statistics.csv` — statistics after cleaning.
- `cleaning_report.txt` — before/after shape, duplicate count, missing-value counts, and cleaning decisions.
- `sales_cleaner.ipynb` — notebook version of the workflow.

```bash

```
To choose another input/output file:
```bash
python sales_cleaner.py --input raw_sales.csv --output cleaned_sales.csv
```

## Cleaning workflow
1. Load CSV with `pandas.read_csv()`.
2. Record original dimensions, null counts, duplicate count, and baseline descriptive statistics.
3. Remove exact duplicates with `drop_duplicates()`.
4. Trim whitespace and standardize text casing.
5. Parse dates into `YYYY-MM-DD`.
6. Fill missing numerical values with the column median. Median is less sensitive to extreme values than mean.
7. Fill missing categorical/text values with the mode; use `Unknown` if an entire column has no mode.
8. Export cleaned data and post-cleaning summary statistics.

## Before/after shape
The sample input contains 25 rows and 7 columns. One exact duplicate row is removed, so the cleaned output contains 24 rows and 7 columns. Missing values are imputed, so the cleaned dataset should have no null values in this sample.

## Null-value rationale
- **Numeric fields** (`Price`, `Quantity`, `Age`): median imputation keeps the pipeline simple and is robust to outliers.
- **Categorical fields** (`City`, `Payment_Method`): mode imputation preserves a common valid category. If no mode exists, `Unknown` is used.
- **Date field**: parse into a consistent ISO-style date string. Invalid/missing date values are coerced and then handled as a text field by the general fill logic.
